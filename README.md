# TV Scroll Capture

إضافة Chrome لالتقاط لقطة ممتدّة لشارت TradingView بدقة البكسل الأصلية.

## التثبيت
1. افتح `chrome://extensions` وفعّل **Developer mode**.
2. اضغط **Load unpacked** واختر هذا المجلد.
3. ثبّت الأيقونة في شريط الأدوات.

## قبل كل التقاط
- أطفئ **Auto Scale** (زر `A` أسفل محور السعر) وإلا تتغير أطوال الشموع بين المقاطع.
- اختر أداة المؤشّر العادية (ليس أداة رسم).
- لا تغيّر الزوم ولا تبدّل التبويب أثناء الالتقاط.
- يُفضَّل إطفاء خط السعر الحي ومؤقّت الشمعة من إعدادات الشارت.

## الوضع الآلي
تسحب الإضافة الشارت بخطوات ثابتة وتلتقط بعد كل خطوة، ثم تتحقق من الإزاحة الفعلية بمطابقة الصور. تتوقف عند انتهاء الخطوات، أو نهاية البيانات، أو 32000px.

## التتبّع العمودي (1.1)
بعد كل خطوة أفقية تفحص الإضافة حافتي اللوحة العليا والسفلى. إذا وجدت شموعاً مقصوصة لم تُلتقط بعد، تسحب الشارت عمودياً وتلتقطها، ثم تكمل. الصورة النهائية تكبر ارتفاعاً حسب الحاجة، والمساحات غير الملتقطة تُملأ بلون الخلفية.
- لوحة الشموع ومحور السعر تُدمج في الاتجاهين.
- لوحات المؤشرات ومحور الوقت تُدمج أفقياً فقط وتوضع أسفل الصورة.
- الرسومات اليدوية أو فواصل الجلسات الملامسة للحافة قد تسبب تحريكات عمودية زائدة، والحد الأقصى يمنع التكرار.

## الوضع اليدوي
اضغط البدء ثم حرّك الشارت بنفسك. الأفضل: انقر على الشارت، أبعد الماوس، واستخدم الأسهم. الإيقاف من الإضافة أو `Alt+Shift+S`.

## ملاحظات
- سيظهر شريط Chrome «TV Scroll Capture بدأ تصحيح هذا المتصفح»، وهذا طبيعي لأن الإضافة تستخدم Chrome DevTools Protocol للالتقاط والسحب. إغلاقه يوقف الالتقاط ويحفظ ما التُقط.
- في تخطيط الشارتات المتعددة تُلتقط أكبر لوحة.
- تسميات محور الوقت قد تتكرر أو تنقص قليلاً عند نقاط الوصل لأن TradingView يعيد توزيعها أثناء التمرير.
